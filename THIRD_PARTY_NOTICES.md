Dependencies retain their own licenses. Cargo.lock records their versions; dependency sources contain the applicable copyright and license texts.

The current interface is Compose Multiplatform. Release packages include the exact runtime dependencies and licenses reported by the relevant build metadata; those generated notices accompany each platform artifact. No manufacturer CAD models, product photos, product meshes, or product textures are shipped. The application uses an abstract signal visualization instead of a simulated Air7 rendering.

The Compose Gradle wrapper is Gradle 9.8.2 (Apache-2.0); its source and license are available from the Gradle project.


Existing release archives include `THIRD_PARTY_LICENSES.html`. New binary distributions must include the applicable dependency/font notices, the project license and corresponding source/build information required by GPL-3.0-or-later.

No vendor code, vendor APKs, firmware images or vendor artwork are distributed.
